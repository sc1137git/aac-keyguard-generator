# AAC Keyguard Generator

將 iPad AAC 畫面截圖轉換成可供 3D 列印的 Keyguard。

## 第一版目標

1. 上傳完整 iPad 螢幕範圍的 AAC 截圖
2. 自動找出可按區域，並允許人工修正
3. 產生黑白 Keyguard 預覽
4. 預設支援 iPad 第 7 / 8 / 9 / 10 代
5. 無耳朵模式：主體厚度預設 3 mm
6. 有耳朵模式：主體厚度預設 5 mm，耳朵厚度 0.8 mm
7. 有耳朵模式的 3D 流程：先鏡像 Keyguard 幾何，再於鏡像後的背面加耳朵
8. 匯出 SVG 與 STL

## iPad 螢幕基準

- iPad 7 / 8 / 9：2160 × 1620 px，實體螢幕座標約 207.82 × 155.86 mm
- iPad 10：2360 × 1640 px，實體螢幕座標約 227.06 × 157.79 mm

上傳圖片只負責提供相對座標，不直接以圖片像素尺寸決定實體大小。

## 部署方向

第一版以單一 Render Web Service 為目標：前端編修介面 + 後端 SVG / STL 生成服務。
